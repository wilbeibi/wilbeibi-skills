# YouTube Obsidian Note Template

Write the entire result to one Markdown file.

## Frontmatter

```yaml
---
title: <descriptive title>
date: <YYYY-MM-DD>
tags: [youtube, video-notes, <topic-tags>]
source: <video URL>
author: <channel or creator>
---
```

## Body

````md
## Metadata

- **Channel/Author:** <name>
- **Source URL:** <url>
- **Duration:** <duration if available>

## Overview

<One paragraph stating the core argument and conclusion.>

## Section Breakdown

### <Topic Name>

- **Timestamp:** <MM:SS or HH:MM:SS>
- **Content:** <detailed explanation in simple language>

> [!quote]
> <Noteworthy short quote, if useful.>

> [!tip]
> <Actionable advice, method, or best practice.>

> [!warning]
> <Pitfall or thing to avoid.>

> [!note]
> <Clarification, uncertainty, or caveat.>

## Key Takeaways

- <Main insight or action item>
````

## Formatting Rules

- Use `##` for main sections and `###` for subsections.
- Bold key concepts on first mention only.
- Use inline code for commands, tools, filenames, and technical terms.
- Keep quotes short; paraphrase long passages.
